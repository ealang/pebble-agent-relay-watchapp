# Store listing assets

Images for the Rebble appstore listing. They are not built into the pbw.

Sizes from the appstore publishing guide
(developer.repebble.com/guides/appstore-publishing/preparing-a-submission):

| Asset | Size | File |
|---|---|---|
| Small icon | 80x80 | `icon_small_80.png` |
| Large icon | 144x144 | `icon_large_144.png` |
| Banner (optional, one per platform) | 720x320 | not made yet |
| Screenshots, up to 5 per platform | basalt / diorite / flint 144x168, chalk 180x180, emery 200x228, gabbro 260x260 | not made yet |

Screenshots must be exactly the display size, with no watch frame around
them. PNG, JPEG or GIF, at most 4.4 MB each.
